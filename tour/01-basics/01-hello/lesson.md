Every Boson source file starts with a `package` declaration. All Boson
executables start in the `main` package, and the program begins in the `main`
function.

Boson provides a `fmt` package to handle string formatting. Its `print`
function takes a format string followed by any arguments, much like `printf`
functions in other C-family languages, and outputs it to the standard output
stream.

Run the program to the right. Then try changing the message and running it again.
